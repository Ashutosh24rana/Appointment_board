# Appointment Board — Frontend (React + Vite + Tailwind)

Env: single project-root `.env` (see `../.env`, Vite `envDir: '../'`) — no `.env` inside `frontend/`.

## Setup
```powershell
cd frontend
npm install
# optional: point at backend — set VITE_API_URL in the root ../.env
npm run dev
```

App: http://localhost:5173 (expects backend at http://localhost:8000)
